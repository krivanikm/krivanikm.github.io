MNPK-01 / 8-bit microcomputer

active_dev · SOČ

Vlastný 8-bitový mikropočítač navrhnutý od logických hradiel až po fyzický plošný spoj. Obsahuje vlastnú inštrukčnú sadu, procesor v SystemVerilogu overovaný simuláciou vo Verilatore, nasadenie na FPGA a vlastnú dosku. Projekt robím ako stredoškolskú odbornú činnosť (SOČ).

A custom 8-bit microcomputer designed from logic gates up to a physical printed circuit board. It covers a custom instruction set, a CPU written in SystemVerilog and verified in Verilator, FPGA deployment and a custom board. I am building it as my high-school research project (SOČ).

ALU ako syscall: kód operácie sa uloží do registra R1 a jedna inštrukcia ALU s tromi registrami ju vykoná. Operácia sa tak dá zvoliť aj počas behu programu.

The ALU as a syscall: the operation code is stored in register R1 and a single three-register ALU instruction executes it, so the operation can even be chosen at run time.

example.asm 
MVI  R1, ADD      ; 0x1100
MVI  R2, 59       ; 0x123B
MVI  R3, 49       ; 0x1331
ALU  R2, R3, R4   ; 0x4234
› R4 = 108

    8-bit CPU Design From Scratch

    Môj prvý komplexný návrh procesorovej architektúry v simulátore Logisim Evolution. Cieľom bolo pochopiť logiku počítačov od základných hradiel až po inštrukčný cyklus. Obsahuje funkčný 8-bitový register file, program counter a inštrukčný dekodér. Inšpirované prácou Bena Eatera a knihou Code od Charlesa Petzolda.

    My first complete CPU architecture design, built in the Logisim Evolution simulator. The goal was to understand how computers work from basic gates up to the instruction cycle. It includes a working 8-bit register file, program counter and instruction decoder. Inspired by Ben Eater's work and the book Code by Charles Petzold.
