MNPK-01 / 16-bitový mikropočítač16-bit microcomputer

active_dev · SOČ

Vlastný 16-bitový mikropočítač navrhnutý od logických hradiel až po fyzický plošný spoj. Obsahuje vlastnú inštrukčnú sadu, procesor v SystemVerilogu overovaný simuláciou vo Verilatore, nasadenie na FPGA a vlastnú dosku. Projekt robím ako stredoškolskú odbornú činnosť (SOČ).

Procesor už beží na reálnom FPGA (Tang Nano 9K) a cez I/O mapované do pamäte ovláda LED a číta spínače. Ako skúšku som na ňom spustil výpočet π na 1950 číslic a Mandelbrotovu množinu (tieto dva programy som vytvoril s pomocou AI asistenta Claude).

A custom 16-bit microcomputer designed from logic gates up to a physical printed circuit board. It covers a custom instruction set, a CPU written in SystemVerilog and verified in Verilator, FPGA deployment and a custom board. I am building it as my high-school research project (SOČ).

The CPU now runs on a real FPGA (Tang Nano 9K) and drives LEDs and reads switches through memory-mapped I/O. As a test I ran 1950 digits of π and a Mandelbrot zoom on it (these two programs were made with the help of the AI assistant Claude).

BRAM — pamäť programu vo FPGA. Synchrónna: dáta prídu až takt po adrese, preto má CU pravidlo časovania (každá inštrukcia ≥ 3 takty).program memory inside the FPGA. Synchronous: data arrive one cycle after the address, so the CU follows a timing rule (every instruction ≥ 3 cycles).
Program counter — 16-bitová adresa aktuálnej inštrukcie. Posunie sa o 1, alebo pri skoku (JMP so 6 podmienkami) načíta cieľovú adresu z registra.16-bit address of the current instruction. It steps by one, or on a jump (JMP with 6 conditions) loads the target address from a register.
Control unit — konečný automat FETCH → DECODE → vykonanie. Dekóduje 16-bitovú inštrukciu a ukladá flagy Z, C, N po každej ALU operácii.a finite state machine FETCH → DECODE → execute. Decodes the 16-bit instruction and stores the Z, C, N flags after every ALU operation.
Register file — 16 registrov po 16 bitoch. Číta celé slovo, zapisuje po bajtoch (MVI/MVIB) alebo celé slovo (MOV, ALU). R1 ide drôtom priamo do ALU.16 registers of 16 bits. Reads a whole word, writes a single byte (MVI/MVIB) or the whole word (MOV, ALU). R1 is wired straight into the ALU.
Data RAM — 4096 slov po 16 bitoch v blokovej pamäti FPGA. Pristupujú k nej iba LOAD a STORE (load/store architektúra ako pri RISC); adresa je v registri.4096 words of 16 bits in FPGA block RAM. Only LOAD and STORE access it (a load/store architecture, as in RISC); the address comes from a register.
ALU — kombinačná 16-bitová jednotka: ADD, SUB, INC, DEC, AND, OR, XOR, NOT, SHL, SHR, ROL, CMP, PASS, CLR. Kód operácie berie z R1 – ako syscall.a combinational 16-bit unit: ADD, SUB, INC, DEC, AND, OR, XOR, NOT, SHL, SHR, ROL, CMP, PASS, CLR. It takes the operation code from R1 – like a syscall.

ALU ako syscallThe ALU as a syscall

Kód operácie sa uloží do registra R1 a jedna inštrukcia ALU s tromi registrami ju vykoná. Operácia sa tak dá zvoliť aj počas behu programu a v opcode ostáva miesto pre ďalšie inštrukcie.

The operation code is stored in register R1 and a single three-register ALU instruction executes it, so the operation can be chosen at run time and opcode space stays free for other instructions.

Kompletný Neovim config, v ktorom vyvíjam aj MNPK-01. Zameraný na C, C++, Assembly, Rust, SystemVerilog a VHDL: jazykové servery, debugger, CMake, Verilator lint a spúšťanie testbenchov jednou skratkou. Inštalátor sa opýta, ktoré jazyky chceš, a nastaví len to, čo potrebuješ.

A batteries-included Neovim config – the one I build MNPK-01 in. Focused on C, C++, Assembly, Rust, SystemVerilog and VHDL: language servers, a debugger, CMake, Verilator lint and running testbenches with a single keymap. The installer asks which languages you want and sets up only what you need.

    My first complete CPU architecture design, built in the Logisim Evolution simulator. The goal was to understand how computers work from basic gates up to the instruction cycle. It includes a working 8-bit register file, program counter and instruction decoder. Inspired by Ben Eater's work and the book Code by Charles Petzold.
